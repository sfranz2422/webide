# Day 5 — Your First Interactive Page

## What you're building

A profile card that reacts when someone clicks the Follow button.

## The three files

| File | What it does |
|---|---|
| `index.html` | The **content** — what's on the page |
| `style.css` | The **appearance** — colours, spacing, fonts |
| `script.js` | The **behaviour** — what happens when you click |

Keeping them separate is the whole point. Change one without touching
the others.

## Your tasks

1. Put your own name and role in `index.html`
2. Change the card's colour scheme in `style.css`
3. In `script.js`, make the button say something different when following

## Watch out for

- A class in CSS starts with a dot: `.card`, not `card`
- An id in CSS starts with a hash: `#follow`
- `getElementById("follow")` uses the **id**, with no `#`

> Open the Console panel underneath the preview. Every `console.log` shows up
> there, and so does any error — with the line number in your own file.
